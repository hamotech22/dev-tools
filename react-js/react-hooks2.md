# شرح useState في React

## الشكل الأساسي

``` js
const [state, setState] = useState(initialValue);
```

-   **state** → القيمة الحالية
-   **setState** → دالة تحديث القيمة
-   **initialValue** → القيمة الابتدائية

------------------------------------------------------------------------

## ما هو useState؟

`useState` هو Hook في React يُستخدم لتخزين البيانات المتغيرة داخل
الكمبوننت.

أي قيمة تتغير أثناء تشغيل التطبيق تحتاج useState.

------------------------------------------------------------------------

## استخداماته (باختصار المفيد)

✅ تخزين القيم المتغيرة\
✅ تحديث واجهة المستخدم تلقائياً\
✅ التحكم في سلوك الكمبوننت

------------------------------------------------------------------------

## أمثلة على الاستخدام

✔ العدادات (Counter)\
✔ المدخلات (Forms / Inputs)\
✔ إظهار / إخفاء عناصر\
✔ تخزين بيانات من API\
✔ التعامل مع Arrays\
✔ التعامل مع Objects\
✔ التحكم في حالات UI (Tabs / Modal / Theme)

------------------------------------------------------------------------

## مثال بسيط

``` jsx
import { useState } from "react";

function Example() {
  const [count, setCount] = useState(0);

  return (
    <button onClick={() => setCount(count + 1)}>
      {count}
    </button>
  );
}
```

------------------------------------------------------------------------

## ملاحظة مهمة

❌ لا تعدّل state مباشرة

``` js
count = count + 1; // خطأ
```

✅ استخدم setter دائماً

``` js
setCount(count + 1); // صحيح
```

------------------------------------------------------------------------

## الخلاصة


`useState` = تخزين + تحديث + إعادة رندر تلقائي 👍
